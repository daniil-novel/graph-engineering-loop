# Graph Engineering Loop

Переносимая копия установленного плагина Codex версии **0.1.0**. Исходные файлы плагина сохранены без изменений.

Плагин задаёт ограниченный цикл инженерной работы: наблюдение → гипотеза → план → действие → проверка → критика → решение. По умолчанию цикл ограничен тремя итерациями; решения и результаты сохраняются в подключённой графовой памяти.

## Установка на другом ноутбуке

Нужны Codex с поддержкой команды `plugin`, Git и доступ к этому приватному репозиторию под аккаунтом `daniil-novel`. Авторизация в GitHub для Git на новом ноутбуке выполняется отдельно.

В терминале выполните по очереди:

```powershell
codex plugin marketplace add daniil-novel/graph-engineering-loop
codex plugin add graph-engineering-loop@graph-engineering-loop
codex plugin list
```

Если первая команда завершилась ошибкой доступа, сначала войдите в GitHub на новом ноутбуке и повторите её. Устанавливайте плагин только после успешного добавления каталога. Затем откройте новый чат Codex и попросите:

> Используй Graph Engineering Loop для этой задачи. Максимум 3 итерации. Сначала определи критерии успешной проверки.

## Отдельная зависимость: графовая память

Этот плагин содержит инструкции и метаданные, **но не содержит MCP-сервер графовой памяти**. Для полного сценария на новом ноутбуке необходимо отдельно подключить сервер графовой памяти с инструментами поиска сущностей, создания сущностей, добавления наблюдений и связей.

Без такого сервера инструкции плагина доступны, но сохранение и поиск долговременной графовой памяти недоступны. Попросите Codex проверить наличие этих инструментов до запуска цикла. Данные существующего графа, настройки других плагинов и учётные данные в этот репозиторий не включены.

## Содержимое

- `.agents/plugins/marketplace.json` — каталог установки из GitHub.
- `plugins/graph-engineering-loop/.codex-plugin/plugin.json` — манифест плагина.
- `plugins/graph-engineering-loop/skills/graph-engineering-loop/SKILL.md` — инструкции цикла.
- `plugins/graph-engineering-loop/skills/graph-engineering-loop/agents/openai.yaml` — метаданные навыка.

## Проверка переноса

После установки проверьте наличие плагина через `codex plugin list` и начните новый чат. Попросите Codex назвать лимит итераций, критерии завершения и доступные инструменты графовой памяти. Установка на втором ноутбуке требует отдельной проверки на том устройстве.
